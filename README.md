# REEFMOTHER ─ 深淵の母・討伐戦

嵐の海で、海賊船の甲板から真鍮の重連弩を撃ち、海の怪物と戦う3D一人称シューティングです。
ブラウザだけで動きます（Three.js）。3Dモデル・テクスチャ・効果音はすべてコードで生成していて、外部の素材ファイルは使っていません。

## 遊ぶ

- **ブラウザで直接**：https://carat0816-oss.github.io/reefmother-fps/
- **Streamlit 版**：`streamlit run app.py`（ゲームをページに埋め込んで表示します）

## ステージ

| | ステージ | 敵 | ボス |
|---|---|---|---|
| 1 | 亡者の入り江（夕暮れ） | 手すりをよじ登ってくる亡者 | 溺死の甲板長 ボースン・グリム |
| 2 | 燐光の珊瑚海（夜・オーロラ） | 近づくと弾ける燐光クラゲ | 潮喰らいの大海蛇 レヴィアタン |
| 3 | 深淵の渦（嵐） | 触手・墨弾・亡者 | 深淵の母 リーフマザー |

各ステージに導入ムービー、ボス登場・撃破ムービーがあります（クリック / Space でスキップ）。

### 射撃分析モード

タイトル画面の「射撃分析モード」から遊べる、ボスなし・30秒のタイムアタックです（亡者と燐光クラゲが途切れず出てくる。矢筒は無制限）。
開始前にプレイヤー名を入れます。時間切れで分析レポートが出ます。

**スコア** ＝ 命中率×400 ＋ HS率×150 ＋ 撃破×25 − 被ダメージ×2 ＋ 初撃の速さ（最大90）。ランクは S≥750 / A≥550 / B≥380 / C。
プレイヤーの平均スコアから技量（上級 ≥650 / 中級 ≥450 / 初級）を出します。

**レポート：この1プレイの操作の分析**（成績は結果なので説明には使わず、操作だけで見る）
- 操作プロファイル：照準移動量、撃つ前0.5秒の照準移動、照準の静止時間、切り返し、マウス移動量、歩いた距離、構え時間の割合、射撃間隔とばらつき、敵との距離、初撃までの時間、追従誤差
- 命中した弾と外れた弾で、撃つ直前の操作を比較（自動で要約文）
- 1プレイ内のロジスティック回帰：命中 ~ 撃つ前の照準移動＋静止時間＋距離＋構え＋移動中（オッズ比のフォレストプロット）
- 敵1体ごと：その敵がいる間の照準移動量と、撃破までの時間

**データラボ**（タイトル／レポートから。記録はこのブラウザの localStorage `reef-lab-v1` に最大200回）
- 一目で比較：軸（スコア・命中率・HS率・撃破数・被ダメ・撃破時間）の上位1/3と下位1/3で、各操作の差を効果量で比較。1回ごと／人ごと
- 相関マップ：操作×成績。全体／個人内（人ごとの平均を引いた相関）
- 散布図：プレイヤー色、全体と人ごとの回帰直線、r・ρ・個人内r
- 因果の手がかり：想定DAG図と、1発単位のロジスティック回帰を「調整なし → 状況（距離・構え・移動）→ ＋人の固定効果 → ＋技量スコア（その回を除いた平均）」と段階的に比較。結果は「関連（調整あり）＝因果の候補」として表示
- データ：一覧、CSV（回ごと・1発ごと）、JSON 書き出し、削除
- サンプルデータ（架空6人×8回、シード固定）で、データが少なくても画面を確認できる

**そのほかのレポート項目**
- 命中率、ヘッドショット率、ヘッドショットで倒した割合、撃破数
- 平均撃破時間（出現から撃破まで）、平均初撃時間（出現から最初に当てるまで）、1体倒すのにかかった射撃数
- 平均交戦距離、外したときの照準のずれ（角度）、DPS、被ダメージ、最大連続命中
- タイムライン（1発ごとの命中・外れ・ヘッドショット、撃破、被弾）、距離別の命中率、命中した部位、構え／腰だめ・静止／移動での命中率の比較、敵の種類別の集計
- 前回との比較、直近12回の推移（ブラウザの localStorage に保存）
- 1発ごとのデータを CSV で保存

## 操作

| キー | 動作 |
|---|---|
| WASD | 移動 |
| ←↑↓→ | 視点（押し続けると速く回る。どちらの視点操作モードでも使える） |
| Shift / Space | 走る / ジャンプ |
| 左クリック / 右クリック | 射撃 / 構える |
| R / Q / E | 装填 / 爆裂矢 / 補給箱 |
| F | 全画面表示 |
| Esc | 一時停止 |

視点操作は2方式から選べます（タイトル画面で切り替え）。

- **マウス固定**：普通のFPS操作
- **カーソル照準**：照準がマウスに付いてきて、画面の端に寄せるとその方向へ振り向く。Streamlit の埋め込み画面ではマウス固定が使えないため、こちらが標準です

## 手元で動かす（Windows）

1. `python -m pip install -r requirements.txt`
2. `start_server.bat` を実行
   - http://localhost:8501 … Streamlit 版
   - http://localhost:8502/game.html … ゲーム単体（マウス固定が使える）
3. 止めるときは `stop_server.bat`

## みんなのデータを集める（Streamlit Community Cloud ＋ Googleスプレッドシート）

Streamlit 版では、射撃分析モードの開始前に「データ提供に同意」した人の記録が、1回ごとにスプレッドシートへ1行ずつたまります。
たまった全員分はゲーム内のデータラボの「みんなのデータ」で、誰でも分析できます。
スプレッドシートの設定がないときは、手元の `data/runs.jsonl` に保存します（動作確認用。Community Cloud ではアプリの再起動で消えます）。
GitHub Pages 版・ゲーム単体（8502）では集めず、記録はそのブラウザにだけ残ります。

**準備（最初の1回）**
1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作り、「Google Sheets API」と「Google Drive API」を有効にする
2. 「IAMと管理 → サービスアカウント」でサービスアカウントを作り、「鍵 → 鍵を追加 → JSON」で鍵ファイルをダウンロードする
3. Googleスプレッドシートを新しく作り、右上の「共有」で、サービスアカウントのメールアドレス（`…@….iam.gserviceaccount.com`）を「編集者」として追加する
4. `.streamlit/secrets.toml.example` を見本に、スプレッドシートのURLと鍵の中身を書いた設定を用意する
   - 手元で試す：`.streamlit/secrets.toml` として保存（Git には上げない。`.gitignore` 済み）
   - Community Cloud：アプリの「Settings → Secrets」に同じ内容を貼り付ける

**公開**
1. このリポジトリを GitHub に push する
2. [share.streamlit.io](https://share.streamlit.io/) で「Create app」→ リポジトリ・ブランチ・`app.py` を選んでデプロイ
3. Secrets を設定すると、最初の保存で `runs` シートと見出し行が自動で作られる

**スプレッドシートの中身**（`runs` シート、1回＝1行）
- `run_id` `received_at` `player` `played_at` `aim_mode`（cursor / lock） `completed` `score`
- 成績：`acc` `hs` `kills` `taken` `ttk`
- 操作：`aimSpd` `preAim` `settle` `revRate` `mouseSpd` `walk` `adsRatio` `gapMean` `gapCV` `nearDist` `react` `track`
- `data_json`：1発ごと・敵1体ごとの細かいデータ（列の並びは `static/game.html` の `SCOL_NAMES` / `FC`）

**運用のメモ**
- 同意した人のデータだけを送る。名前はニックネームにしてもらう（同意欄に注意書きあり）
- 不適切な名前や、消してほしいと言われた記録は、スプレッドシートの行を消せばゲームからも消える（1分ほどで反映）
- ゲームに渡すのは新しい順に600回まで。1回の接続で受け付けるのは40回まで
- 視点操作の方式（埋め込み画面のカーソル照準／別ウィンドウのマウス固定）で操作の数値の性質が変わるので、`aim_mode` で分けて分析するとよい

## ファイル構成

- `static/game.html` … ゲーム本体（これ1ファイルで完結）
- `static/index.html` … Streamlit のコンポーネント用の入口（game.html へ転送）
- `app.py` … Streamlit 版の入れ物（ゲームを双方向コンポーネントとして埋め込み、データを受け取って保存・配布）
- `store.py` … データの保存先（Googleスプレッドシート／ローカルファイル）
- `.streamlit/secrets.toml.example` … Secrets の見本
- `index.html` … GitHub Pages 用（ゲームへ転送）
